# Reports

Generated by the project's scripts. Small tables, figures and reports are committed; trained model files and downloaded data are not (see `.gitignore`).

- `model_report.md`, `metrics_table.csv`, `topk_table.csv`, `calibration_table.csv`, `metrics_by_claim_type.csv`, `metrics_by_month.csv`, `feature_importance_gain.csv`, `shap_importance.csv`, `example_explanations.csv`, `run_log.csv`, `figures/`: from `python -m src.training.train`
- `root_cause/`: from `python -m src.analysis.root_cause` (denial reasons by count and dollars, root-cause categories and owners, provider concentration, figures, report)
- `rag_eval.md`, `rag_eval_cases.csv`: from `python -m src.rag.evaluate` (appeal copilot evaluation)
- `appeal_examples/`: from `python -m src.rag.demo` (example drafts from local claims)
