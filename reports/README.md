# Reports

Generated by `python -m src.training.train`. Small tables, figures and the model report are committed;
trained model files and the downloaded feature table are not (see `.gitignore`).

- `model_report.md`: full results with assumptions
- `metrics_table.csv`: baselines, LightGBM, calibrated LightGBM and the oracle ceiling (valid and test)
- `topk_table.csv`: review-queue results (probability ranking vs expected-loss ranking, with net benefit)
- `calibration_table.csv`, `metrics_by_claim_type.csv`, `metrics_by_month.csv`
- `feature_importance_gain.csv`, `shap_importance.csv`, `example_explanations.csv`
- `run_log.csv`: one row per training run (commit, parameters, headline metrics)
- `figures/`: ROC and PR, calibration, cumulative dollar gains, SHAP bar and summary
